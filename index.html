About Me

I am an Application & Cloud Security Engineer with 5+ years of cybersecurity experience, currently at Bristol Myers Squibb. I focus on driving and expanding the Application Security program, working closely with engineering teams to identify vulnerabilities, understand security risks, prioritize findings, and drive practical remediation strategies.

My work spans identifying and remediating vulnerabilities across applications, APIs, and cloud platforms, while helping development teams integrate security into their workflows and practices. Beyond traditional vulnerability discovery, I am deeply interested in security automation, Agentic AI, security engineering, and identifying gaps in existing security capabilities to build practical solutions that scale.

I am particularly focused on:

  • Application Security: Helping teams identify, understand, and remediate vulnerabilities while improving secure development practices.
  • Cloud Security: Strengthening security across AWS, IAM, infrastructure, and cloud-native environments.
  • Security Automation: Replacing repetitive manual processes with scalable automated workflows.
  • Security Engineering: Integrating security into the software development lifecycle and CI/CD pipelines.
  • Agentic AI for Security: Exploring how AI agents can investigate findings, understand context, and assist security teams and developers.
  • Security Innovation: Identifying gaps between existing security capabilities and what teams actually need, then building practical solutions.
